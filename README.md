# Siłownia — apka treningowa (wersja zbudowana)

Ten katalog zawiera wyłącznie zbudowaną aplikację publikowaną przez GitHub Pages: https://noum3n.github.io/workout/

Kod źródłowy, plany i dokumentacja są w prywatnym repozytorium. Nie edytuj tych plików ręcznie — są generowane
(`tools/publish_web.sh`). Dane użytkowników nie trafiają do tego repozytorium; klucz Supabase w `index.html`
jest kluczem publicznym (publishable), a dostęp do danych chronią reguły bazy (RLS).
